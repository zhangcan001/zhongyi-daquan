# AI 知识库助手 v0.2 方剂回答

## 目标

AI 知识库助手在回答经方、方剂、治疗思路、证候相关问题时，优先展示本地知识库中已有的原方资料，减少用户在详情页、条文和注解之间来回查找。

## 回答格式

涉及方剂时，每个候选方尽量输出：

- 方剂名。
- 关联证候或条文。
- 本地资料原方组成。
- 原文剂量。
- 药材比例。
- 原文煎服法。
- 本地注解摘要。
- 适用描述。
- 谨慎或不适用情况。
- 来源引用。

如果本地资料中没有组成信息，回答必须显示“本地资料中未检索到完整组成”，不得编造。

## 检索范围

方剂问题优先检索：

- `knowledge_items.type = formula`。
- `formula_details`。
- `knowledge_items.detail` 中的 `composition`、`ingredients`、`dosage`、`usage`、`decoction_method`、`original_formula`、`original_text`、`explanation` 等字段。
- `knowledge_annotations` 的 `content`、`detail_json`、`tags_json`、`source_title`、`source_note`。
- `knowledge_items` 中原典条文、证候、注解、正文、`source_note`、`tags`。

当用户输入症状或证候而不是方名时，系统会先检索相关条文、证候和注解，从结果中提取方剂候选，再继续检索每个候选方的组成、煎服法和注解。

## 比例提取

系统提供轻量规则函数 `extract_formula_ratio(composition_text)`：

- 支持中文数字：一、二、三、四、五、六、七、八、九、十、半。
- 支持单位：两、枚、升、合、钱、分。
- 同单位药材计算比例。
- 不同单位不换算，显示“另计”。
- 解析失败时不报错，只展示原文组成。

示例：

```text
桂枝三两 芍药三两 甘草二两 生姜三两 大枣十二枚
```

输出：

```text
桂枝 : 芍药 : 甘草 : 生姜 = 3 : 3 : 2 : 3；大枣十二枚另计。
```

## 安全边界

- 允许展示本地知识库中的原方组成。
- 允许展示古籍或讲义中的原文剂量。
- 允许展示药材之间的比例。
- 允许展示原文煎服法。
- 允许展示本地资料中的方剂注解。
- 不自动换算成现代个人处方。
- 不根据用户个人情况直接给“应该吃多少克、吃几天”的执行指令。
- 不替代医生处方。
- 不提供针灸操作指导。
- 所有方剂组成必须带来源。

当用户要求具体个人剂量、加减和疗程时，助手只展示本地资料中的原文剂量和比例，并提示需要专业中医师结合面诊确认。
