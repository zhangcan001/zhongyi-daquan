# v0.1.2 搜索与阅读体验优化

## 目标

v0.1.2 聚焦“查资料、看资料、看来源、看注解、返回、复制、收藏、个人备注”的真实使用体验。当前阶段不继续扩展导入架构，不解析 PDF，不调用真实 AI。

## 搜索

首页学习工作台顶部提供全局搜索框：

```text
搜索中药、方剂、穴位、经络、原典、注解……
```

增强搜索会按类型分组显示：

- 中药
- 方剂
- 穴位
- 经络
- 原典章节
- 原典条文
- 注解资料
- 其他

每条结果显示名称、类型、分类、命中摘要、来源、注解数量、导入批次或来源包。关键词会在名称、摘要、正文片段、来源和注解命中片段中高亮。

无结果时提示：

- 换一个关键词试试
- 如搜索黄芪未命中，可试试黄耆
- 确认是否已导入相关数据包

## 详情页

知识详情按区块展示：

- 主信息：名称、类型、分类、别名、拼音、来源、标签、导入批次。
- 正文：summary 和 content。
- 类型专属信息：中药、方剂、穴位、经络、原典等字段按标签分区显示。
- 资料注解：独立展示 `knowledge_annotations`，不与主条目混成一段。
- 操作：返回、复制、收藏、个人备注。

## 注解来源

注解显示来源标题和来源备注，例如：

```text
3人纪-神农本草经.pdf | 上经 | 人参 | PDF页码26-27
```

注解默认展开前 1-2 条；长注解通过折叠块查看全文。搜索命中注解时，进入详情后会打开包含命中词的注解。

## 最近查看

打开详情时写入 `recent_views`，字段包括：

- `item_id`
- `item_name`
- `item_type`
- `category`
- `viewed_at`

首页显示最近查看 5-10 条。最近查看只用于本地学习记录，不影响主数据。

## 收藏与个人备注

收藏写入 `user_favorites`，并同步主表 `is_favorite`，用于兼容既有列表。

个人备注写入 `user_notes`，当前为轻量版：每个条目保留一条本地学习备注，可编辑或删除。备注不参与医疗建议、诊断、开方或针灸操作指导。

## 导入历史

首页显示最近导入批次摘要。查看报告和回滚入口仍在 Smart Import Center；回滚前必须二次确认。首页不展示 manifest、字段映射或导入技术细节。

## 安全边界

本软件仅用于中医知识学习、资料整理与本地记录，不提供：

- 在线问诊
- 自动诊断
- 自动开方
- 针灸操作指导
- 医疗处置建议
